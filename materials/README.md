# Папка для материалов

Сюда складываются файлы лекций и заданий, по подпапке на дисциплину:

```
materials/
  mdk-05-02/              МДК.05.02 Разработка кода ИС
  osnovy-algoritmizacii/  Основы алгоритмизации и программирования
  informatika/            Информатика
```

Называйте файлы латиницей, без пробелов: `pr4-php.docx`, `lekciya-html.pdf`.
Так ссылки не сломаются ни в одном браузере.

Для студентов удобнее PDF: он открывается прямо в браузере, в том числе на телефоне.
Один файл на GitHub должен весить меньше 100 МБ.
