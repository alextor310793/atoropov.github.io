# Сайт преподавателя Торопова А.В.

Статический сайт на HTML и CSS для GitHub Pages. Сборка, базы данных и платные услуги не нужны.

## Что где лежит

```
index.html                  главная: дисциплины, правила сдачи, о себе, контакты
disciplines/*.html          страница каждой дисциплины
materials/                  файлы лекций и заданий
css/style.css               оформление всего сайта (тема «редактор кода»)
404.html                    страница «Такой страницы нет»
```

Места, которые нужно заполнить, записаны в квадратных скобках и подчёркнуты жёлтой волной, как предупреждение в редакторе кода.
Найти их все можно поиском по `class="todo"`. После того как вписали свой текст, удалите `class="todo"`, и подсветка пропадёт.

## Как опубликовать на GitHub Pages

1. Зарегистрируйтесь на github.com. Логин станет частью адреса сайта.
2. Создайте публичный репозиторий с именем `логин.github.io`, где вместо «логин» стоит ваш логин.
3. Загрузите в него все файлы из этой папки: Add file → Upload files. Перетащите содержимое папки (не саму папку) и нажмите Commit changes.
4. Откройте Settings → Pages. В блоке Build and deployment выберите Source: Deploy from a branch, ветку `main`, папку `/ (root)` и нажмите Save.
5. Через одну-две минуты сайт откроется по адресу `https://логин.github.io`.

Если репозиторий назван иначе (например, `site`), адрес будет `https://логин.github.io/site/`. Сайт при этом работает так же, страница 404 тоже.

## Как добавить файл лекции или задания

1. Загрузите файл в нужную подпапку `materials/`, например `materials/mdk-05-02/pr4-php.pdf`.
2. Откройте страницу дисциплины и в строке этой работы замените
   `<span class="soon">файл появится</span>`
   на
   `<span class="files"><a href="../materials/mdk-05-02/pr4-php.pdf">Задание</a></span>`.

## Объявления-комментарии

Строки вида `// Новое: ПР №4 по PHP` (`<aside class="note">`) — это короткие объявления: новая работа, срок сдачи.
Меняйте текст после `// ` по мере надобности или удаляйте блок целиком. Лучше уложиться в одну строку.

## Оформление

Сайт оформлен как открытый файл в редакторе кода — по профилю студентов (09.02.07, 09.02.12):
номера строк слева, цвета подсветки синтаксиса у заголовков, кодов специальностей и номеров работ.
Все цвета собраны в начале `css/style.css` в блоке `:root` — там их и меняйте.
Номера строк ставятся автоматически, вписывать их не нужно.

## Если GitHub плохо открывается

Сайт состоит из обычных файлов, поэтому его можно без переделок перенести на любой хостинг: скопировать папку целиком.
